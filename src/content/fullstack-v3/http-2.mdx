**HTTP/1.1** makes an independent connection for every file. `index.html` is a
request and a response. `app.js` is another. `style.css` another. It works, and
it's what most of the internet still runs on.

**HTTP/2 multiplexes**: several things at once over one connection, which is
usually faster.

So why isn't it universal? **It costs more CPU** — someone has to multiplex and
demultiplex all those streams. For a site this size it's free money; at scale
it's a trade you make on purpose.

## Enabling it

The easiest change in the entire course. Find the `listen` lines certbot added
for 443 and add one word:

```nginx
listen 443 ssl http2;
listen [::]:443 ssl http2;
```

```bash
sudo nginx -t
sudo service nginx restart
```

<Callout label="Confirm it">
Open devtools, go to the Network tab, and right-click the column headers to add
**Protocol**. It'll now say `h2` instead of `http/1.1`. You'll also see the
WebSocket sitting there as `101 switching protocols` on `wss` — the upgrade
status code from the previous lesson, in the wild.
</Callout>
