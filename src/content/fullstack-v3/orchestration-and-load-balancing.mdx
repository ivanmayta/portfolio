You made two containers by hand. Now imagine thousands — brought up, upgraded,
taken down. That's **orchestration**, and it's a full-time job for people.

**Kubernetes** is the name you've heard, and that's what it does: manages your
containers. Docker Swarm and Apache Mesos do the same thing. None of them are
worth standing up for two containers on one droplet.

## Balancing across them

Two servers where all the traffic hits one is pointless. A **load balancer**
distributes requests, and nginx already is one.

<Figure
  src="/diagrams/fullstack-v3/load-balancer"
  alt="nginx proxying to a named upstream that lists three containers on different local ports."
  caption="Add a container, add a line. nginx handles the rest."
/>

In `/etc/nginx/nginx.conf`, inside the `http` block:

```nginx
upstream nodebackend {
    server localhost:3000;
    server localhost:3001;
}
```

Then in your server block, change one line:

```nginx
proxy_pass http://nodebackend;
```

Instead of naming a port, you name a **cluster**, and nginx decides.

## Which one gets it

| | |
|---|---|
| **round robin** | 1, 2, 3, 1, 2, 3. The default |
| **IP hash** | this address block always goes to that server |
| **least connections** | the least busy — but you have to *count* connections |
| **least load** | the least loaded — but you have to *measure* load |

Every clever algorithm costs a measurement. There's a neat middle ground raised
in the room: **sample two servers at random and pick the better one.** You get a
surprisingly even distribution while inspecting two machines instead of a
thousand.

<Callout label="See the load yourself">
`htop` on the server — the Unix Activity Monitor, less shiny, more useful. It's
how you answer "why is this slow" and how you find the process to `pkill`.
</Callout>

## Prove it's balancing

Add a log format that records the upstream, point `access_log` at it, then:

```bash
sudo tail -f /var/log/nginx/access.log
```

Refresh a few times and you'll watch requests alternate between 3000 and 3001.
Believing it is fine. Watching it is better.
